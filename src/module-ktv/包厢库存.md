# KTV 包厢库存

库存没有单独的数量字段，也不会在下单时给某个数字做加减。可售数量是当场数出来的，扣库存就是写入一笔仍占用时段的订单。取消后订单不再占用，名额自动回到可售。

## 可售数量

按门店、包厢类型计算。只统计这家店、这个类型、启用并且空闲的包厢个数。停用、使用中、打扫中、维修中、临时关闭都不计入。

包厢上的「容纳人数」只表示能坐多少人，不参与库存。

这个类型没有空闲包厢时，可售数量是 0。下单直接拒绝，提示「该包厢类型没有可售包厢」。小程序的可预订列表也不展示这种类型。

## 占用区间

一笔订单占用的是一个时间段，左闭右开：

`[开唱时刻, 开唱时刻 + 演唱小时数)`

开唱时刻由预订日期和开唱时间拼成。小时数是 1 到 24 的整数。结束可以落到第二天，比较时用这段绝对时间，不拿钟点在同一天里比。

相邻两笔刚好接上时不算冲突。例如 16:00 唱 2 小时，占到 18:00；下一笔从 18:00 开始，两笔可以同时存在。

昨天开唱、小时数跨进今天的订单，今天这段重叠时间里仍然占名额。

## 扣库存

创建预订在同一个事务里完成：

1. 锁定该包厢类型，确认它属于这家店且仍启用。
2. 数出该类型启用且空闲的包厢个数，作为可售数量。数量为 0 时拒绝，提示「该包厢类型没有可售包厢」，不扣余额。
3. 锁定同一门店、同一类型、时段相交、且状态仍占用的订单。
4. 已占用笔数大于或等于可售数量时，拒绝下单，提示「该时段已订满」，不扣余额。
5. 否则写入一笔待核销订单。这时还没有具体包厢，订单已经占掉这个类型的一个名额。
6. 按「每小时价格 × 小时数」扣会员余额。扣款失败时订单一起回滚，名额不会留下。

仍占用名额的状态：待核销、已核销、已完成。已取消、已退款不占用。

## 归还库存

后台取消待核销或已核销的订单时，状态改为已退款，并退回包厢费。已退款不在占用名单里，这个类型的名额随即空出。已分配的包厢也不再被这笔订单占住。取消不会把包厢从使用中改回空闲，要在包厢状态页手动改。

已完成的订单不能取消，它继续占着原来的时段。

## 核销时分配包厢

核销不改变类型名额。名额在下单时已经扣过。

核销只是给这笔待核销订单选一个具体包厢，成功后把这个包厢改成使用中。不填核销码的线下开包厢不产生订单，只把空闲包厢改成使用中：

- 包厢必须是同一门店、同一类型、启用，并且当前是空闲。
- 这个包厢在该订单的时段内，不能已有另一笔已分配的占用订单。待核销订单还没有包厢，不会挡住某一个具体包厢。
- 选中的包厢冲突时，提示「该时段没有空闲包厢」，订单保持待核销。

## 酒店

酒店预订不按日期计算或扣减房间库存。下单只校验门店和房型，不锁房间、不扣余额。入住时要求房间当前是空闲，然后把房态改成占用；退房后再改回空闲。房费在退房时按实际晚数结算。
